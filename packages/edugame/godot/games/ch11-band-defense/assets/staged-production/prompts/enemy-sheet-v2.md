# Enemy Sheet V2 Prompt

Use case: stylized-concept
Asset type: game sprite source contact sheet for a Godot educational tower-defense game
Primary request: Create a polished production-quality contact sheet of six moving enemy units that read clearly as abnormal data packets and unstable signal faults, not towers.
Subject: Six distinct enemy units in a 3 by 2 grid: configuration error packet, sensor noise swarm, false peak spike cluster, power spike surge cell, drift noise wave cloud, hybrid fault composite anomaly.
Style/medium: high-detail stylized 3D game sprite source art, isometric three-quarter view, crisp silhouettes, readable at small size, matching a light futuristic PCB educational game.
Composition/framing: each enemy isolated in its own equal panel, centered, generous padding, consistent scale, all enemies should look like they are moving left-to-right along a path.
Enemy shape language: asymmetric, unstable, no pedestal, no stable base, no vertical tower posture. Use floating shards, broken data slabs, waveform spikes, glitch trails, small hovering circuit fragments, corrupted packets, drifting particles, and forward motion streaks.
Lighting/mood: cool studio lighting with orange warning glow and purple fault electricity, soft ambient occlusion, subtle rim light.
Color palette: dark graphite data fragments, damaged black panels, orange warning cracks, purple electrical fault accents, cyan corrupted signal lines, tiny glitch pixels.
Materials/textures: beveled hard-surface fragments, cracked casing pieces, tiny circuit traces, glowing waveform pieces, error pixels, broken bus connectors, transparent signal wisps.
Constraints: no tower, no turret, no pedestal, no base platform, no upright building silhouette, no creature, no animal, no face, no weapon, no readable text, no labels, no logo, no watermark, no UI chrome. The enemy identity must be understandable by motion shape, silhouette, and icon-like internal graphics only.
Avoid: static hardware blocks, defensive modules, cute characters, monsters, guns, cannons, fantasy magic, solar panels, PID/PWM/servo imagery, large in-image words or numbers.
