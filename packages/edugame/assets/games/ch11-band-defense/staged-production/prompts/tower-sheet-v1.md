# Tower Sheet V1 Prompt

Use case: stylized-concept
Asset type: game sprite source contact sheet for a Godot educational tower-defense game
Primary request: Create a polished production-quality contact sheet of four defense towers representing trusted smartwatch data-processing modules.
Subject: Four distinct defense towers in a 2 by 2 grid: I2C initialization tower, signal filter tower, peak detection tower, low-power wakeup tower.
Style/medium: high-detail stylized 3D game asset render, clean isometric three-quarter view, production game art, crisp silhouettes, readable at small size.
Composition/framing: each tower isolated in its own equal panel, centered on a compact base, generous padding, consistent scale, no overlapping panels.
Lighting/mood: bright clean diagnostic lab lighting, calm blue/cyan glow, green trusted-data validation accents.
Color palette: white ceramic hardware, pale blue glass, cyan data lines, green validation light, subtle navy screen surfaces.
Materials/textures: beveled medical-device plastic, glass diagnostic panels, small chips, ports, circuit traces, holographic waveforms, battery cell indicator.
Constraints: no weapon barrel, no cannon, no missile, no readable text, no labels, no logo, no watermark. The tower identity must be understandable by silhouette and technical visual cues only.
Avoid: combat turrets, fantasy towers, solar panels, PID/PWM/servo imagery, large in-image words or numbers, dark villain styling.
