# Enemy Sheet V1 Prompt

Use case: stylized-concept
Asset type: game sprite source contact sheet for a Godot educational tower-defense game
Primary request: Create a polished production-quality contact sheet of six small enemy units representing abnormal smartwatch data-link problems.
Subject: Six distinct enemy units in a 3 by 2 grid: configuration error data block, sensor noise packet, false peak signal module, power spike battery fault, drift noise cloud module, hybrid fault combined anomaly.
Style/medium: high-detail stylized 3D game asset render, clean isometric three-quarter view, production game art, crisp silhouettes, readable at small size.
Composition/framing: each unit isolated in its own equal panel, centered, generous padding, consistent scale, no overlapping panels.
Lighting/mood: cool studio lighting with controlled orange and purple fault glows, soft ambient occlusion, subtle rim light.
Color palette: enemies are dark graphite hardware, damaged black panels, orange warning cracks, purple electrical fault accents, tiny glitch pixels.
Materials/textures: beveled hard-surface plastic and metal, cracked casing, tiny circuit traces, glowing waveform screens, error pixels, broken bus connectors.
Constraints: no creature, no animal, no face, no weapon, no readable text, no labels, no logo, no watermark, no UI chrome. The enemy identity must be understandable by silhouette and icon-like internal graphics only.
Avoid: cute characters, monsters, guns, cannons, fantasy magic, solar panels, PID/PWM/servo imagery, large in-image words or numbers.
