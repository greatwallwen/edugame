# Font Sources

This game bundles fonts for the chapter 11 Godot Web export.

- `DingTalkJinBuTi.ttf`
  - Source: DingTalk JinBuTi official download page.
  - Use in game: display titles, short buttons, and compact labels.
  - Download page: https://page.dingtalk.com/wow/dingtalk/default/dingtalk/y-W5aF3_ZJwzulU0nceIl

- `Orbitron-wght.ttf`
  - Existing project font.
  - Use in game: small telemetry/numeric accents only.

- `ZCOOLQingKeHuangYou-Regular.ttf`
  - Existing project font.
  - Use in game: long Chinese body copy, diagnosis text, tutorial copy, and quiz prompts.

- `NotoSansSC-VF.ttf`
  - Existing project font.
  - Use in game: compact HUD readouts and longer quiz answer buttons where readability matters most.
